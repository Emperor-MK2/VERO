# Barbershop "VERO" Landing

Адаптивный одностраничный сайт для барбершопа с возможностью онлайн-записи и автоматической отправкой заявок в Telegram.

## 🔗 Демо
[Посмотреть сайт](https://vero.zenro.ru)

## 🚀 Технологический стек
* **HTML5** (Семантическая верстка)
* **CSS3** (Flexbox, CSS Grid, адаптивность под Mobile/Tablet/Desktop)
* **Vanilla JavaScript** (Работа с DOM, валидация форм)
* **AOS** (Библиотека анимаций при скролле)
* **Telegram Bot API** (Отправка заявок через прокси-сервис Layero)

## ✨ Главные фишки проекта
* 📱 **Mobile-first:** Полная адаптивность под любые устройства (от 320px до 4K).
* 🤖 **Умная форма:** Валидация полей ввода (проверка имени и телефона).
* 🔔 **Интеграция с Telegram:** Заявки с сайта мгновенно приходят владельцу бизнеса в Telegram-бота. Работает без VPN (через Layero).
* 🎨 **Современный UI/UX:** Плавные анимации появления блоков (AOS), интерактивные hover-эффекты.
